# NaviGoo Web Prototype

A GitHub Pages-ready static prototype based on the NaviGoo mobile UI reference.

## Run locally

No Node.js is required.

Open `index.html` in a browser.

## Publish on GitHub Pages

1. Put `index.html`, `style.css`, `app.js`, and `README.md` in the root of the repository.
2. Commit and push to the `main` branch.
3. GitHub → Settings → Pages.
4. Under Build and deployment choose **Deploy from a branch**.
5. Branch: `main`, folder: `/ (root)`.
6. Save.

The site is a single-page prototype. Buttons navigate between the major NaviGoo flows and use demo data.

## Important

This is a front-end prototype. Real GPS, maps, payments, login, databases, driver/mechanic matching, and AI need backend/API integration later.
